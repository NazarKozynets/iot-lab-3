# Перевірка моделі

У Packet Tracer 9.0.1 перевірено обмін між реальними програмами пристроїв і правилами сервера. Журнал `packet-tracer.log` містить стани детектора та сирени: 0 → 1 → 0, зокрема продовження тривоги повторним рухом. Події вводилися викликом штатного `mouseEvent` у середовищі детектора; команду сирені передавали серверні Conditions.

Після остаточного виправлення DNS 24.11.2026 модель збережено й повторно відкрито. DHCP працює на маршрутизаторі, на сервері вимкнений. Планшет отримав адресу 10.3.0.102/24, шлюз 10.3.0.1 та DNS 10.3.0.2. За адресою http://iot.home відкрилася панель із трьома підключеними пристроями. Скріншоти `lab3-client-dns.png` і `lab3-dns-home-final.png` підтверджують цю перевірку.

`network-status.txt` — адреси під час попереднього тесту сигналізації; DHCP може видати інші адреси при наступному відкритті. Статична адреса сервера завжди 10.3.0.2.
